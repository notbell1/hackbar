## 1. 100% Local-First Commitment

ZX HACKBAR is engineered with a strict **local-first privacy architecture**:
- **Zero Telemetry**: The extension transmits no analytical pings, telemetry, crash reports, or diagnostic metrics to any third-party or developer server.
- **Zero Remote Dependencies**: All libraries (React, Zustand, Dexie, Lucide icons, fonts, CSS) are packaged locally in the extension bundle. No external CDNs or remote scripts are contacted.
- **Zero Tracking**: No user identifiers, fingerprinting cookies, or telemetry beacons are generated or stored.
- **Offline Capable**: All core features (parsing, multi-format encoding, template generation, DIOS watermarking) run offline without requiring internet access.

## 2. Local Data Storage & Management

All data generated by ZX HACKBAR remains strictly within your browser's local sandbox:

| Data Type | Storage Engine | Purpose | Retention |
| :--- | :--- | :--- | :--- |
| **Application Preferences** | `chrome.storage.local` | UI theme, Sync Tab state, and layout preferences | Until cleared by user |
| **Scope Allowlist** | IndexedDB (`ZXHackbarDB`) | Stores authorized target domains to prevent accidental out-of-scope requests | Until deleted by user |
| **Request & Evidence History** | IndexedDB (`ZXHackbarDB`) | Stores HTTP request/response logs for audit report generation | Until cleared by user |
| **Custom Test Vectors** | IndexedDB (`ZXHackbarDB`) | Stores user-created payloads and favorite tags | Until deleted by user |

---

## 3. Automated Credential Redaction

To protect against inadvertent token leakage when exporting audit logs or saving history, ZX HACKBAR masks sensitive headers by default before committing them to local IndexedDB:
- `Authorization` (Bearer tokens, Basic auth credentials)
- `Cookie` and `Set-Cookie` (Session tokens)
- `X-API-Key`, `API-Key`, `Token`
- `Proxy-Authorization`

Redacted headers are converted to `[REDACTED]` in the local history repository.

---

## 4. User Control & Data Deletion

You maintain complete ownership and control of your local data:
- **Purge History**: Click the red trash icon in the **History** tab to instantly delete all saved request logs.
- **Remove Scopes**: Delete any authorized origin in the **Scope** tab.
- **Export / Backup**: Export test vectors and history to JSON or Markdown at any time.
- **Complete Uninstall**: Uninstalling the extension permanently wipes all IndexedDB databases and `chrome.storage.local` keys from Chrome.

---

## 5. Chrome Permissions Explanation

The extension requests only minimal, necessary Chrome permissions:
- `sidePanel`: Required to render the interface inside Google Chrome's Side Panel.
- `storage`: Required to save local UI preferences and state.
- `tabs`: Used exclusively to synchronize URL from the current active tab when clicking *"Active Tab"* or *"Sync Tab"*.
- `contextMenus`: Adds a convenience right-click menu item (*"Open URL in ZX HACKBAR"*).
- `optional_host_permissions` (`http://*/*`, `https://*/*`): Requested on-demand per origin when sending HTTP requests, preventing broad static access.
